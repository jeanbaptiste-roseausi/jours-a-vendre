# Spécifications

Une spécification par fonctionnalité, rédigée et validée **avant** tout test et tout code.

Une spécification décrit ce que l'utilisateur saisit, ce qui doit s'afficher, les règles de calcul et des exemples chiffrés. Ces exemples deviendront les tests.

Une spécification n'est validée que lorsque le responsable du projet l'a approuvée. Aucune règle métier n'y est ajoutée sans son accord.
